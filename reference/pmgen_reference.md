# Specify a Reference Model for Sample Size Calculations

Constructs a reference logistic regression model by finding the
intercept and coefficient scalar that jointly achieve a target
prevalence and c-statistic in the joint predictor distribution. The unit
Fisher information matrix is also computed and stored in the returned
object.

## Usage

``` r
pmgen_reference(
  joint_data,
  predictors = NULL,
  coef = NULL,
  bisection = TRUE,
  bisection_method = c("independent", "mvn"),
  intercept = NULL,
  prevalence = NULL,
  cstatistic = NULL,
  tolerance = 0.001,
  n_bisect_pop = 1e+06,
  n_synth = 1e+06,
  max_iter = 100,
  seed = NULL
)
```

## Arguments

- joint_data:

  A data frame (one row per individual, columns = predictors)
  representing the joint predictor distribution. Alternatively, a named
  list of distributional assumptions (see Details). Required.

- predictors:

  Character vector of predictor column names to use from `joint_data`.
  If `NULL`, all columns of `joint_data` are used (when `joint_data` is
  a data frame).

- coef:

  Named numeric vector of predictor coefficients. Names must match
  `predictors`. Meaning depends on `bisection`: when `bisection = TRUE`,
  these are *relative weights* (on the log-odds scale, before scaling) —
  if `NULL`, all predictors are given equal weight of 1. When
  `bisection = FALSE`, these are the *final* coefficients used directly
  (no default; must be supplied).

- bisection:

  Logical. If `TRUE` (default), run the two-step bisection procedure to
  calibrate `coef`/`intercept` against `prevalence`/ `cstatistic`. If
  `FALSE`, bypass bisection entirely and use the supplied
  `intercept`/`coef` directly as the reference model — useful when a
  reference model has already been fully specified elsewhere (e.g. from
  the literature) and bisection-based calibration is not wanted.

- bisection_method:

  One of `"independent"` (default) or `"mvn"`. Only used when
  `bisection = TRUE` and `joint_data` is a data frame. `"independent"`
  calibrates against a synthetic population generated by fitting
  independent marginal distributions to `joint_data` (fast, but discards
  correlation between predictors). `"mvn"` instead calibrates against a
  synthetic population drawn from a multivariate normal approximation to
  `joint_data` that preserves its correlation structure (binary columns
  are dichotomized after generation); see Details. `"mvn"` is not
  supported when `joint_data` is a distributional- assumptions list
  (predictors are already independent there by construction).

- intercept:

  Numeric scalar. Required when `bisection = FALSE`; ignored when
  `bisection = TRUE` (the intercept is instead solved for by the inner
  bisection).

- prevalence:

  Target outcome prevalence (0, 1). Required when `bisection = TRUE`.
  Optional when `bisection = FALSE` — if supplied, the achieved
  prevalence is compared to it for informational reporting only.

- cstatistic:

  Target c-statistic (AUC), must be \> 0.5. Required when
  `bisection = TRUE`. Optional when `bisection = FALSE` — if supplied,
  the achieved c-statistic is compared to it for informational reporting
  only.

- tolerance:

  Convergence tolerance for both bisection procedures. Default `0.001`.
  Unused when `bisection = FALSE`.

- n_bisect_pop:

  Integer. Size of the super-population used internally during
  bisection. Larger values give more stable estimates but are slower.
  Default `1e6`. Unused when `bisection = FALSE`.

- n_synth:

  Integer. When `joint_data` is a distributional-assumptions list, the
  number of synthetic individuals to generate. Default `1e6`.

- max_iter:

  Integer. Maximum bisection iterations. Default `100`. Unused when
  `bisection = FALSE`.

- seed:

  Integer or NULL. Random seed for reproducibility.

## Value

A `pmgen_ref_model` object with components: `coef`, `intercept`,
`prevalence_achieved`, `cstat_achieved`, `predictors`, `joint_data`,
`unit_info_matrix`, `inv_unit_info`.

## Details

**Supplying a dataset** (`joint_data` as a data frame): The data frame
is used directly as the super-population for bisection and for computing
the unit information matrix. This is the recommended approach when
synthetic or real pilot data are available.

**Supplying distributional assumptions** (`joint_data` as a named list):
Each list element specifies the marginal distribution of one predictor:
`list(dist = "normal", mean = 50, sd = 10)` or
`list(dist = "bernoulli", prob = 0.3)`. Predictors are assumed
independent. A synthetic population of `n_synth` rows is generated
before bisection.

The bisection procedure follows Austin's two-step approach:

1.  **Inner bisection (intercept)**: for a fixed scalar `s`, find the
    intercept `b0` such that mean(plogis(b0 + s \* X %\*% coef)) =
    prevalence.

2.  **Outer bisection (scalar)**: find `s` such that the c-statistic of
    the resulting model in the super-population equals `cstatistic`.

**Bypassing bisection** (`bisection = FALSE`): supply `intercept` and
`coef` directly as the final reference model. This is useful when the
reference model's coefficients are already known (e.g. published in the
literature) and bisecting against a synthetic population derived from
`joint_data` is undesirable — for instance, because it would assume
predictor independence when `joint_data` is a data frame (see
`.fit_marginals()`). The unit information matrix is still computed from
`joint_data` as usual.

**Correlation-preserving bisection** (`bisection_method = "mvn"`): when
`joint_data` is a data frame with correlated predictors, calibrating
against a synthetic population that assumes independence (the default
`"independent"` method) can distort the calibrated reference model. The
`"mvn"` method instead estimates a multivariate normal approximation to
`joint_data` (means, SDs, and the full correlation matrix, via
[`cor()`](https://rdrr.io/r/stats/cor.html)) and analytically solves for
the linear predictor's mean and variance needed to hit the target
`prevalence`/`cstatistic` (assuming a normal linear predictor), then
rescales `coef` so the resulting predictor combination has that
variance. Binary (0/1) columns are generated as normal and then
dichotomized to match their empirical proportion; this mildly attenuates
their correlation with other predictors relative to the input
correlation matrix (no correction is applied for this).

Note that bisection without `coef` gives every predictor the same
coefficient. If the predictors' true effects differ (in size or sign),
this equal-weights model can give noticeably different simulation
results (e.g. a different expected calibration slope at small N) from
the true model; supply `coef` (relative weights) where they are known.

## Examples

``` r
# n_bisect_pop and n_synth are reduced from their defaults (1e6) so that
# the examples run quickly; use the defaults in practice.

# From a supplied dataset (equal relative weights for all predictors)
predictors <- setdiff(names(dvt_data), "dvt")
ref <- pmgen_reference(
  joint_data   = dvt_data,
  predictors   = predictors,
  prevalence   = 0.21,
  cstatistic   = 0.78,
  n_bisect_pop = 1e5,
  n_synth      = 1e5,
  seed         = 42
)
#> Running bisection to calibrate reference model...
#> Bisection converged: prevalence=0.2100 (target=0.2100), c-stat=0.7791 (target=0.7800)
#> Unit information matrix computed and cached.
ref
#> pmgen reference model
#> ---------------------
#>   Predictors        : male, OCuse, malignancy, surgery, ab_leg_trauma, vein_distension, calf_diff, ab_ddimer, pregnancy, immobile, clotting
#>   Intercept         : -4.7089
#>   Prevalence (achieved): 0.2100
#>   C-statistic (achieved): 0.7791
#>   Coefficients      :
#>            male           OCuse      malignancy         surgery   ab_leg_trauma 
#>          0.9375          0.9375          0.9375          0.9375          0.9375 
#> vein_distension       calf_diff       ab_ddimer       pregnancy        immobile 
#>          0.9375          0.9375          0.9375          0.9375          0.9375 
#>        clotting 
#>          0.9375 
#>   Unit info matrix  : cached (12x12)

# From distributional assumptions
ref_dist <- pmgen_reference(
  joint_data = list(
    age  = list(dist = "normal",    mean = 0, sd = 1),
    bp   = list(dist = "normal",    mean = 0, sd = 1),
    hist = list(dist = "bernoulli", prob = 0.3)
  ),
  prevalence   = 0.10,
  cstatistic   = 0.75,
  n_bisect_pop = 1e5,
  n_synth      = 1e5,
  seed         = 42
)
#> Running bisection to calibrate reference model...
#> Bisection converged: prevalence=0.1000 (target=0.1000), c-stat=0.7491 (target=0.7500)
#> Unit information matrix computed and cached.

# Bypassing bisection with a fully pre-specified reference model
ref_fixed <- pmgen_reference(
  joint_data = dvt_data,
  predictors = c("malignancy", "calf_diff", "ab_ddimer"),
  bisection  = FALSE,
  intercept  = -2.5,
  coef       = c(malignancy = 0.5, calf_diff = 0.8, ab_ddimer = 1.5),
  n_synth    = 1e5,
  seed       = 42
)
#> Using supplied reference model (bisection bypassed): prevalence=0.2541, c-stat=0.7068
#> Unit information matrix computed and cached.
```
